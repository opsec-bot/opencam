# Attribution and data licensing

opencam's output datasets are a derived database under the
[Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/),
because they are built from OpenStreetMap data.

If you use opencam data, you must:

- Attribute **© OpenStreetMap contributors**.
- Keep the data available under ODbL if you distribute a modified version.

## Sources

- **OpenStreetMap** — base layer for speed, red-light and ALPR cameras, via the
  Overpass API. © OpenStreetMap contributors, ODbL.
- **DeFlock** *(planned)* — crowd-sourced Flock/ALPR camera mapping, itself
  OSM-based. Exact data access to be confirmed before integration.
- **US municipal open-data portals** *(planned)* — per-city authoritative camera
  locations; each city's own open-data license applies and will be listed here
  as adapters are added.

opencam does not include data scraped from closed or proprietary services.
